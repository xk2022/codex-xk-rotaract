# 後端

此目錄將存放 Xk-rotaract 的 API、業務邏輯、資料存取與後端測試。目前為規劃階段，預設採 Java 21、Spring Boot 3.5、Spring Security、PostgreSQL 17 與 Flyway（詳見[需求基準](../docs/2027/13-requirements-baseline.md)），尚無實作或經驗證啟動命令。

第一階段依核心使用流程定義 [API 契約](../docs/api/README.md)，涵蓋請求、回應、錯誤與存取權限，再完成前後端串接。

加入實作後，補上實際驗證過的安裝、啟動、測試、資料庫設定與必要環境變數說明。
