# Xk-rotaract

採用 monorepo 管理前端、後端與協作文件的專案。

目前已建立目錄骨架與 AI 團隊規範。產品需求、技術棧與部署環境仍待確認；尚無可啟動的前後端應用程式，尚未啟用自動化測試、CI 或部署。

## 目錄

| 路徑 | 用途 | 目前內容 |
| --- | --- | --- |
| `frontend/` | 前端畫面與互動 | 規劃文件 |
| `backend/` | 後端 API 與業務邏輯 | 規劃文件 |
| `docs/` | 需求、架構、API 契約與團隊規則 | 協作文件 |
| `.github/workflows/` | GitHub Actions | 目錄占位，尚未設定工作流程 |

設計目標為前後端各自建置、測試與部署，具體方式於技術選型後確認；跨模組變更在同一個 pull request 中協調。

## 開始開發

1. 閱讀 [代理協作規則](AGENTS.md) 與 [團隊分工](docs/TEAM.md)。
2. 確認第一個核心流程，記錄使用者角色與驗收條件。
3. 建立可點擊的前端雛形，同步定義 [API 契約](docs/api/README.md)。
4. 選定技術並完成一條前後端串接流程，再加入經驗證的啟動、測試與 CI 命令。

已確認事項與待決策項目見 [架構紀錄](docs/architecture.md)。
