## 接手方式

1. 每個獨立個體先讀本儲存庫 AGENTS 與 [codex 管理中心](https://github.com/xk2022/codex)最新適用規則。
2. 選定一份主要任務包，使用其中的可貼上啟動指令，先核對最新來源與已完成事項。可逆分析及任務內工作依既有授權推進；正式資料、支出、敏感設定等按現有核准界線處理。
3. 建立自己的任務分支，避免與其他個體共改同一檔案或共用測試資料庫；變更共享契約先交總管協調。
4. 回報來源版本、完成範圍、修改檔案、實際驗證、缺口與下一步。沒有正式啟動紀錄時，維持待辦；停止或受阻時不宣稱 Agent 仍在背景工作。
