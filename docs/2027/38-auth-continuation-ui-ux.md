# 登入／註冊後接續原操作

日期：2026-10-15。完成八項工具的第5項前端假資料流程；正式後端維持暫停。

## 使用流程

- 公開頁登入／註冊入口帶入原頁面；驗證成功後返回原社團、活動、商家或公開列表。
- 社團詳情「註冊後申請加入社團」帶入社團與入社意圖。註冊成功後開啟入社表單並預選原社團，提供返回原社團連結。
- 仍須本人填入社說明並明確送出，社團管理者核准後才取得社籍。建立帳號不會自動入社或曝光。
- 已有正常／待確認社籍或待審入社申請者，顯示既有進度／轉社入口，避免重複申請。
- 從登入畫面改建立帳號、忘記密碼及登入失敗不消耗返回意圖。
- 入社留言未送出時，離開、關閉或Esc須確認放棄；取消保留草稿。成功送出／明確關閉後移除接續參數。
- 社團已失效、不公開或停用時不預填，回到申請工作區並提示重新選擇。公開社團若尚未對應到入社管理名單（目前高雄示範），改顯示未開放線上申請與聯絡提示，不提供誤導的入社CTA。

## 返回位置與權限

- 僅允許同一網站公開hash：首頁、商家地圖、行事曆、社團列表，以及帶單一安全ID的社團／活動／商家詳情。
- 拒絕外部網址、協定相對網址、腳本、任意後台路徑、雙重編碼、重複返回參數及附加詳情參數。無效意圖回一般登入後的工作區。
- 入社意圖只接受社團詳情目標，執行時再檢查可公開、啟用且存在的社團；匿名不開啟接續入社視窗。
- 不改既有送審、轉社或社籍資格檢查；公開商家返回不授予優惠／商家示範身分。
- 不把帳密、表單內容或個資存入網址或localStorage；網址只保存公開目標與入社意圖。
