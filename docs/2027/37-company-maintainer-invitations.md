# 公司共同維護邀請：前端假資料

日期：2026-10-15。接續八項回訪與銜接工具的第4項；不新增後端或依賴。

## 入口

- `#/demo?view=invitations`，選單「公司共同維護邀請」。
- 商家維護頁提供入口；待辦中心選擇明確的商家示範身分，可查看收到的待回覆邀請及發出後等待對方回覆的邀請。
- 邀請與商家維護共用記憶體狀態；接受或撤銷後立即反映到維護權限，重新整理還原。

## 行為與界線

- 公司建立者選已註冊會員發出邀請。不能邀自己、已接受維護者，或重複發出同公司同會員的待回覆邀請。
- 只有受邀本人可接受或拒絕；建立者可取消未處理邀請，並撤銷已接受或既有範例維護者。
- 接受、拒絕、取消與撤銷均有確認。公司／邀請版本不符時拒絕覆寫，須重新確認。
- 接受僅加入 `acceptedMaintainerIds`；不變更owner、`acceptedMemberIds`、社籍、廣告、首次發布時間或公司公開狀態。
- 撤銷只移除維護權，保留獨立的會員關聯；不刪公司、優惠或社籍。
- 公司暫停時不能接受邀請，仍可取消或撤銷；邀請不會解除暫停。
- 公司資料維護與優惠建立／核銷權限分開，優惠仍僅公司owner可操作。
- 受邀未接受前只看必要公司名、邀請時間與權限說明，不顯示私人營業聯絡或位置。
- 其他會員、訪客與內容管理角色不能讀取私人邀請；示範角色切換不是正式授權。
