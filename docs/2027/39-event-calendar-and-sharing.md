# 活動加入個人行事曆與分享

日期：2026-10-15。八項工具第6項；純前端，不新增後端、第三方服務或套件。

## 操作

- 公開活動詳情的「保存與分享」提供ICS下載、複製活動連結與手機／系統分享。
- 未支援系統分享或剪貼簿被拒絕時顯示完整唯讀連結，可選取手動複製；取消系統分享只提示已取消。
- 取消活動提供「下載取消狀態（ICS）」與取消提醒；分享標題也標示已取消。
- 草稿、會員／社內活動、封存或撤下內容不提供公開保存分享介面。ICS匯出函式亦檢查公開投影，不能藉直接呼叫匯出私有活動。

## 行事曆格式

- RFC5545 VCALENDAR／VEVENT，CRLF換行，文字反斜線／逗號／分號／換行跳脫。
- 每行最多75個UTF-8位元組，折行不切斷中文字或emoji。
- 指定時間以UTC DTSTART／DTEND匯出，個人行事曆依使用者時區顯示；跨日保留實際起迄。
- 全天採VALUE=DATE，結束日不含，沿用活動資料規則。
- 同活動在同網站路徑有穩定UID，版本映射SEQUENCE；取消輸出STATUS:CANCELLED，維持METHOD:PUBLISH單次匯入。
- 分享及檔案內URL保留GitHub Pages子路徑，只帶公開活動ID，不攜原頁查詢或登入參數。

## 使用限制

- [x] 單次檔案下載、複製、裝置分享及手動備援。
- [ ] 訂閱行事曆與自動同步更正／取消；本輪未提供。
- [ ] 正式活動API、通知、報名、簽到及付款；本輪未提供。

下載成功不等於已加入個人行事曆，須由使用者開啟檔案並確認匯入。行事曆軟體對重複匯入、更正及取消處理不同，不能保證自動更新或移除原紀錄；參與前須回活動頁確認最新公告。本網站活動仍為合成資料。
