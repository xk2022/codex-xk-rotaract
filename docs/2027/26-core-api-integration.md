# 第一階段核心 API 串接

更新：2026-10-15。本次交付將合成資料展示與本地 API 串接分開；第一階段整體尚未完成。

## 本次範圍

以既有 OpenAPI 與需求基準實作「個人註冊 → 登入 → 申請入社 → 所屬社團管理者核准 → 登入後會員名冊」。註冊不自動入社、不自動登入，也不讓未獲准會員出現在名冊。

預設前端仍為 GitHub Pages 使用的合成資料展示。設定 `VITE_API_MODE=live` 才啟用本地串接；管理權限以伺服器 Session 與有效社團授權為準。公開根路徑仍是首頁。

## 開發環境

- Java 21、Maven 3.9 以上、Node.js 24、Docker Compose。
- API：Spring Boot 3.5、Spring Security、PostgreSQL 17、Flyway。
- 資料庫僅對本機開放 `127.0.0.1:55432`；持久化在 Compose named volume。
- 本地 HTTPS 用於維持 `__Host-session` 的 Secure／HttpOnly／SameSite=Lax Cookie，不將正式安全規則改成 HTTP。
- 密碼、資料庫密碼、冪等雜湊密鑰及 TLS 私鑰只放本地環境或被忽略的檔案，不提交版本控制。

```sh
cp .env.example .env
# 編輯 .env，設定本地隨機資料庫密碼。
docker compose up -d postgres
bash scripts/create-local-tls.sh
```

API 環境變數、初始化資料與啟動命令見[後端說明](../../backend/README.md)；前端模式及 HTTPS 命令見[前端說明](../../frontend/README.md)。產生的憑證為開發用自簽憑證；正常瀏覽器操作宜使用本機信任的憑證。自動化測試只對本地測試憑證設定信任例外。

`docker compose stop` 保留本地資料。`docker compose down` 移除服務但保留 named volume；刪除 volume 會刪除本地資料，不是一般停機步驟。可選的 `mail` profile 僅預留 Mailpit，本次未實作寄信與復原信件。

### 本輪修正

| 問題 | 修正 |
| --- | --- |
| 撤權後可重送已成功的審核key取得舊結果 | 回放前重查當前社團授權，隱私欄位按目前設定再次遮罩 |
| 敏感回放內容以明文保存，過期key未定期清除 | AES-256-GCM驗證加密、隨機nonce、綁定請求範圍的AAD及每60秒過期清理；不允許明文回退 |
| 切換Email／電話／代號可分散登入失敗計數 | 帳號限流依永久accountId，另有IP限流；失敗註冊節流不因業務交易回滾而消失 |
| 入社拒絕冷卻誤以申請時間計算 | 以實際拒絕時間起算24小時 |
| 密碼前端依UTF-16計長、網路重試換key | 改用Unicode碼點、不截斷或去空白；同輸入未知結果保留key，成功／登出清除 |
| 返回公開頁仍殘留隱藏私人DOM、撤權後沿用舊社團選項 | 公開頁不渲染私人內容；重新依有效範圍校正選擇 |
| 不合法入社日期被分類為服務失敗 | 回400且保持申請與社籍資料不變 |
| Spring產生不使用的預設帳號、CI硬編本機瀏覽器路徑 | 排除預設帳號自動配置；未指定路徑時使用Playwright安裝的瀏覽器 |

完整13個operation與啟動設定見[後端說明](../../backend/README.md)。其餘46個契約operation尚未實作；13/59僅是端點數，**不是第一階段完成百分比**。名冊目前在伺服器應用層投影與篩選，1萬會員負載尚未驗證；核心稽核只有追加事件，完整差異、查詢與保留排程待完成。
