秘書可配置一般管理角色，依先前接受的「社長／秘書／社團管理帳號可改角色」規則；年度新任一般管理角色的重新分配由社長主導。一般管理者不得給自己升權。

| 平台角色 | 可執行 | 不自動取得 |
| --- | --- | --- |
| 權限管理員 | 地區／平台授權、初始管理者、撤權與交接案件 | 私人聯絡修改、任意公開歷史、財務 |
| 帳號支援 | 有證據人工復原、舊會員認領、停復權案件 | 私人名冊批量讀取、社團核准、無證據換 Email |
| 內容／曝光管理員 | 公司公開內容事後退回／暫停、公開內容案件、廣告日期與啟停 | 任意角色授予、付款確認、直接改私人資料 |
| 帳務管理員（階段 4） | 人工付款核對、調整／作廢及退款紀錄 | 社籍、其他平台權、公開個資 |
| 維運人員 | 部署、健康、遮罩系統日誌、備份作業 | 應用個資讀取、歷史 override、社團操作 |
| 特定 admin | 額外 history:override 的指定歷史公開例外 | 通用超級管理權或其他個資權 |

平台角色可兼任但每項獨立授予。首次建立平台權限管理員由部署 bootstrap 處理；後續高權授予不可自行審核，必須由另一名有效權限管理員執行並留下紀錄。
