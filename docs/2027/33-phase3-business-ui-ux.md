# 第三階段前端：公司名錄、商家詳情與會員維護

更新：2026-10-15。依使用者確認，第三階段先做前端 UI／UX 與合成資料。後端維持暫停，廣告對帳與優惠核銷留在第四階段。

## 畫面與入口

| 畫面 | 路徑 | 目的 |
| --- | --- | --- |
| 商家名錄／地圖 | `#/map`（相容 `#/BizMap`） | 名稱、Call Name、社團、城市與產業搜尋，名錄與分布示意連動 |
| 商家公開詳情 | `#/business?id=coffee` | 可直接開啟／重新整理的公開營業資訊頁 |
| 商家維護與審核示範 | `#/demo?view=businesses` | 公司草稿、公開設定、人工座標、送審與內容管理員審核 |

公開根網址維持首頁，管理App延遲載入。商家詳情由舊彈窗改為獨立路由；不存在、未審核、暫停或無曝光資格資料一律顯示公開不存在頁。

## 資料、隱私與曝光

- 公司電話、Email、網站、營業地址獨立填寫與公開勾選，不使用會員私人聯絡資料。
- 公開回應採白名單；本人姓名、owner/member ID、非公開聯絡與審核原因不放入公開詳情。
- 一公司可有多個已接受的關聯會員／維護者，仍只產生一筆公司結果及一個標記。邀請與接受先使用固定已接受樣本，本輪不宣稱完整邀請流程已完成。
- 公司需審核通過、具曝光資格且至少一項營業聯絡公開才進入公開名錄。
- 有已接受關聯會員的當年度有效社籍、社團啟用，提供免費資格；七月寬限按年度邊界處理，八月不延續上一年度免費資格。
- 付費曝光只用唯讀合成權益預覽，期限起始日加一曆年、不含迄日，閏日次年取二月二十八日；有效廣告優先顯示「廣告」文字與色彩。付費不繞過公司審核、公開設定或定位同意。
- 停用社團會立即影響免費資格；仍有另一關聯會員資格或獨立有效廣告者可繼續曝光。
- 無座標公司可出現在名錄，不能產生標記；標記需位置公開同意與有效座標。營業地址不公開但明確同意公開人工營業位置者可顯示座標，不自動以地址推定位。

## 會員維護與審核

- 建立者與已接受維護者可修改公司；社團／地區管理身分不自動取得他人公司修改權。
- 草稿 → 送審 → 通過／退回；內容管理員可暫停已通過公司，退回／暫停須理由。
- 已通過公司修改後回草稿並撤下公開，需重新送審；舊版本審核不得核可新資料。
- 欄位錯誤、版本衝突與操作失敗保留輸入；離頁與切換示範身分需確認未儲存變更。
- 商家示範身分是此工作區的展示控制，不代表原「平台帳號支援」自動具有內容管理權或正式登入授權。

## 地圖交付邊界

本輪沒有配置Google Maps瀏覽器key、供應商帳務或地理編碼服務。畫面清楚標示分布示意，不能當真實街道、導航或定位結果。保留等價公司列表、手動座標與供應商替換邊界，不自動要求定位、不呼叫geocoding。
