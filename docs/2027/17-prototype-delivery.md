# 第一版操作雛形與契約交付

日期：2026-10-15。範圍為需求基準之後的第一個可審閱交付，未發布或部署。

## 已完成

- 前端 React 19／TypeScript 5／Vite 7／Tailwind 4，自有元件延續紅色品牌、淺灰背景與側欄卡片；不使用未取得授權的商用模板。
- 管理總覽、會員名冊／詳情、入社申請、社團唯讀資料、本人資料及隱私、年度補確認、三段轉社。
- 訪客、會員本人及兩個社團管理身分的示範切換，所有資料為合成，固定業務日2026-10-15；只存頁面記憶體，密碼不保存。
- 註冊→申請入社→該社核准後列名冊；拒絕原因、撤回、同類待審限制；詳情遵守聯絡資訊隱私。
- 轉社雙方核准不自動生效，本人最終確認後更新；保留原社歷史快照與預設隱藏設定，原社歷史獨立入口不取得新聯絡資料。
- 正式 OpenAPI 3.1 JSON：59個操作、84個DTO，626個合成JSON範例；額外補齊可操作所需讀取、年度版本、原社待辦及未登入人工復原閉環。
