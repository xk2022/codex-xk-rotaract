# 第二階段：已發布活動內容更正

更新：2026-10-15。延續第二階段前端 UI／UX，補齊活動發布後的內容更正，不啟動後端、不提前進入第三階段商家地圖或第四階段優惠核銷。

## 使用流程與權限

有發布權的原主辦單位管理者 → 更正活動內容 → 預覽與欄位驗證 → 確認公開影響 → 儲存 → 原活動詳情與公開行事曆同步更新。

- 活動 ID 與已發布狀態保持不變，不需要先取消再複製。
- 社長、秘書、備援可更正本社已發布活動；地區管理者可更正本地區主辦活動。
- 一般社團管理者仍只可維護草稿，不能藉此更正已發布內容。
- 不能變更主辦單位；已取消／已封存活動不可原筆編輯。
- 時間、全天、時區、內容與可見性沿用既有驗證；更正私人可見性後，訪客不得繼續閱讀原詳情。
- 儲存前顯示確認，取消確認保留輸入；版本不符拒絕覆蓋，保留尚未儲存的內容。
- 未儲存離頁仍需確認，取消離開時保留編輯器。

仍是共用記憶體假資料，重新整理會還原。版本檢查與角色限制只是前端模型；正式 API 授權、資料庫併發及異動歷史待恢復後端工作後實作。本輪不聲稱通知參加者、寄信、活動報名、簽到、金流或核銷已完成。

第二階段後續仍保留：組織停復用跨模組同步、正式資產、完整輔助科技驗收與 SEO。第三階段才擴充公司名錄／地圖，第四階段處理廣告與優惠。
