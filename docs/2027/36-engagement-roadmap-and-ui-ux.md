## 入口與使用方式

- `#/demo?view=tasks`：「待辦與提醒」，頁首通知鈴亦進入此頁。
- `#/demo?view=reports`：「商家回報追蹤」；公開商家詳情亦可進行明確標示的回報假資料體驗。
- `#/demo?view=confirmations`：「我的商家確認」；公開商家或商家已隱藏的提示頁均提供入口。

所有頁面只用記憶體合成資料，重新整理即還原。社籍、商家回報與確認的示範身分明確分開，切換展示身分不等於實際登入。待辦中心預設不讀取任何商家私人提醒，須自行選擇「商家提醒身分」。

## 商家回報與追蹤

- [x] 會員就目前公開商家回報公司不存在、地址錯誤、資料冒用或其他，填寫具體說明。
- [x] 同會員同公司未結案防重，訪客不見私人案件，會員只見本人案件。
- [x] 內容管理員附說明接案，調查後附結果結案；版本不符拒絕覆寫。
- [x] 公司隱藏後既有案件仍可從回報工作區追蹤；公開詳情不揭露他人案件。
- [x] 案件狀態篩選、未送出草稿離開保護與手機排版。

回報不自動下架，也不把建議地址直接覆寫正式公司資料。更正由商家維護者依查證結果處理；暫停由既有內容管理流程操作。此輪只呈現最新處理說明與結果，不宣稱具有正式完整稽核歷程。

- [x] 本人確認公司、確認時間、一年截止（不含）、是否仍計入及商家公開狀態。

「仍計入」依既有確認資格計算，與「商家公開中」分開。撤回會移除本次確認，並非另建永久歷史稽核；再次確認仍需符合原規則。
