# 第四階段前端：會員優惠、兌換碼與商家核銷

更新：2026-10-15。依使用者指示開始優惠功能，沿用需求基準 B11。後端與付款維持暫停；本輪為共用記憶體合成資料 UI／UX。

## 操作入口

- 工作區：`#/demo?view=coupons`，選單「會員優惠與核銷」。
- 商家詳情提供「登入使用會員優惠」及清楚標示的假資料體驗入口；匿名公開頁不放會員兌換碼。
- 商家假資料身分與平台工作區身分分開，不把帳號支援或社團管理身分自動當公司 owner／內容管理員。

## 生命週期與資格

1. 公司 owner 建立優惠草稿，填優惠內容、使用條件、起迄時間、總名額、每帳號上限。
2. 送審後由內容管理員核准或附理由退回；可附理由暫停優惠。
3. 登入且具當年度 active／confirmed 社籍、所屬社團啟用者可領取。七月寬限、付費廣告、三日商家曝光或六人確認標章不授予領券資格。
4. 新領取還須優惠已核准、在效期內、公司目前公開且有曝光資格；額滿及每帳號達上限不可再領。
5. 領取後產生一次性碼，僅本人在「我的優惠」查看。商家 owner 輸入碼、核對最小必要資訊並確認，才轉為已核銷。

商家公司自行發布與優惠前置審核是兩個不同流程。已接受公司維護者不自動取得優惠建立／核銷權，本輪依基準採 owner。

## 邊界與一致性

- 時間採UTC記錄，台北時間輸入與顯示；開始含該時刻、結束不含該時刻。
- 總名額及每人上限須正整數。已領、已用、作廢皆占已分配名額，不自動返還，避免反覆領取。
- 同一領取請求重送回到原紀錄，不重複扣名額；相同識別碼不能改領另一優惠。
- 已領碼保存當下優惠內容、條件與到期時間；後續優惠編輯不延長或縮短已領券。
- 已核准優惠修改後回草稿重新送審，新領取暫停；已領券依快照使用，優惠／公司被平台暫停則阻止核銷。
- 公司曝光自然到期會停止新領，已領券不因曝光到期自動失效。
- 重複、過期、作廢、跨公司與非 owner 核銷皆拒絕；核銷確認綁券及優惠版本，過期畫面不覆蓋新狀態。
- 作廢由本人處理且填寫原因，無付款、退款或支付憑證。
- 失敗與版本衝突保留輸入；切身分或離開未儲存表單有捨棄確認。

## 優惠體驗優化（2026-10-15）

- 領取前即顯示本人已達上限或額滿原因，停用領取按鈕，避免完成確認才被拒絕。
- 增加三步驟引導、搜尋結果數與清除篩選；手機選優惠後移至詳情並聚焦，鍵盤亦可接續操作。
- 我的優惠新增全部／未到期且未使用／已使用／到期／作廢篩選、未到期且未使用數量，以及複製代碼成功與失敗提示。
- 優惠或公司暫停時，錢包與核銷結果明確提示暫停使用，核銷按鈕停用；不改原有資格、到期與名額規則。
- 手機核銷碼輸入關閉自動大寫與拼字檢查，避免改變大小寫敏感的代碼。
- 驗證：124項單元測試與正式建置通過；優惠瀏覽器流程補驗達上限提前阻擋與錢包狀態篩選。
