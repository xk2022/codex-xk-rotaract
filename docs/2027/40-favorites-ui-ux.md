# 商家、社團與活動收藏清單

日期：2026-10-15。八項工具第7項，前端記憶體假資料；不新增後端、持久化或套件。

## 入口與操作

- 公開商家、社團、活動詳情有「收藏此內容」，選擇明確標示的收藏示範會員後加入／取消收藏。
- `#/demo?view=favorites`，選單「我的收藏」，集中查看三種類型，可依類型篩選、搜尋、清除篩選及逐筆移除。
- 同一瀏覽過程共用收藏身分與資料。切換會員時清除原篩選／操作提示，並只顯示新身分本人收藏；訪客不顯示任何收藏。
- 會員只需為已註冊的示範帳號，不要求正常社籍；收藏本身不取得社籍、曝光或其他權限。

## 資料與狀態

- 儲存僅為收藏ID、本人ID、類型、目標ID及建立時間，不保存名稱、聯絡、地址或其他內容快照。
- 新增時再次確認目標在目前公開投影內。同會員、同類型、同目標去重；不同會員可各自收藏。
- 清單即時依目前公開投影顯示名稱及詳情連結。
- 商家隱藏／曝光到期、社團不公開或停用、活動私有／撤下／封存／失效時，只顯示一般不可查看提示與移除按鈕，不顯示原名稱或詳情連結。
- 公開取消活動仍可收藏，但在清單標記活動已取消，並引導查看最新公告。
- 只允許本人移除收藏；即使目標已失效或曝光時間無效，仍可移除。

「失效」不代表刪除收藏紀錄，目標再次公開後會顯示當前公開資料。搜尋不使用已隱藏內容的舊名稱。

## 限制與待辦

- [x] 三類內容收藏、本人清單、篩選搜尋、失效狀態與移除。
- [ ] 真實登入／伺服器本人授權、收藏API與持久化。
- [ ] 跨裝置同步、備份與正式會員資料連結。

收藏示範身分獨立於正式登入及其他工作區展示角色，不能視為真實授權。重新整理或重設示範資料會還原；不使用localStorage保存會員收藏。沒有自動通知、追蹤第三方服務或自動分享。
