## 使用者體驗驗收清單

- [ ] 從社團註冊，確認預填社團正確、未自動送出，完成申請後可查看進度。
- [ ] 會員建立商家，體驗72小時與資格到期；提醒能接到正確公司。
- [ ] 回報資料問題、管理員處理、本人看結果；公司隱藏後仍可撤回本人確認。
- [ ] 邀請另一會員維護，接受後有權、撤銷後失權，且未取得優惠核銷權。
- [ ] 活動下載／分享、三類收藏與隱藏失效提示符合預期。
- [ ] 社團年度確認與下任社長／秘書指定，總覽數值與實際操作一致。

以上保留待使用者實際驗收，不把工程自動測試視為使用者同意，也不要求重新確認已接受的業務規則。

## 必須保留的展示限制

- 各模組身分切換是獨立的合成展示，不是真實登入或權限；新註冊帳號未自動映射商家示範會員。
- App社籍與BusinessMember曝光資格目前為不同合成資料來源；App年度確認／入社不會自動改商家fixture資格。商家曝光以商家示範身分與時間為準，正式整合須統一會員來源。
- 所有新增工具只用記憶體，重新整理重設；沒有跨裝置同步、真實通知或伺服器併發保證。合成資料會隨前端下載，畫面遮蔽不等於正式資料保密。
- 真實地圖、廣告申請與人工對帳、付款、優惠核銷API仍未完成。ICS不是訂閱，不自動同步；收藏不是持久化。
- 已有17個operation的本地會員／社團核心API與本人帳號串接，沿用[先前交付證據](27-account-and-privacy-integration.md)；本輪沒有重新執行真實API驗證，也沒有擴大或部署後端。
