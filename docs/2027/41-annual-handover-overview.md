# 年度交接總覽

日期：2026-10-15。八項回訪與銜接工具第8項；唯讀彙整現有年度名冊與角色資料，不增加授權操作或後端。

## 入口與權限

- `#/demo?view=handover`，選單「年度交接總覽」。
- 社團管理者僅本社；地區管理者僅目前授權地區，只有角色交接入口，不能由此進行社員年度確認。
- 一般會員、訪客與平台帳號支援角色不提供交接資料。
- 角色交接入口帶入原社團，保留demo／workspace根路徑與原身分；既有角色頁仍自行限制社團與職務範圍。
- 停用社團只供備查，不提供處理按鈕或計入下任就緒人選。

## 指標定義

- **社員年度確認**：正常／待確認社員為分母，排除OB、退社與無社籍。已確認且確認年度至少為目前示範年度才列入完成；缺少年度的既有正常樣本以2026計。空名冊不標100%。
- **舊年度提示**：全域示範年度切換但其他社團尚未套用其名冊切換時，不把其舊正常狀態誤算已完成，提示到年度名冊檢查。總覽不修改他社社員。
- **到期提醒**：觀察日仍在任且90天內到期的角色；最後任期日仍有效，隔日為過期。
- **下年度接任**：以觀察日所屬7/1～6/30年度的下一個7/1為準，分別檢查社長、秘書各一位；任期涵蓋該日，且為本社正常社員。一般管理者不補缺，過期、待確認或已離社不當作有效人選，重疊資料標示需檢查。

「已指定」只表示7/1有人選，不表示已到任或涵蓋全年，畫面列出完整任期供核對。觀察日僅預覽角色，不變更社員年度、不提前授權；社員完成率依年度頁目前示範年度計算，兩者明確分開。

## 操作銜接

- 前往既有年度名冊確認社員，回總覽立即更新完成數。
- 前往角色頁使用「帶入下年度任期」，指定社長／秘書，回總覽更新接任準備。
- 總覽僅顯示範圍內必要call name與任期，不輸出會員姓名、電話或Email。
