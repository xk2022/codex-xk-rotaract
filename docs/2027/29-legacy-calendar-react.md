# 公開行事曆：沿用舊版資訊架構，以 React 重做

更新：2026-10-15。依使用者確認，保留舊版「地區 → 社團 → 日期 → 活動」操作邏輯與品牌配色。後端仍暫停，使用既有共用合成資料；管理示範發布或取消活動可同步反映公開頁，重新整理重設。

## 重做理由與保留設計

舊版參考來源為 `xk2022/xkRotaract` 固定提交 `0c2aad93e1127b5e99b9e65bbd3adb7f3d7b2788` 的 `templates/calendar/index.html` 與 `static/plugins/custom/evocalendar/evo-calendar-rotaract.js`。保留地區列、年度月份側欄、日曆與活動區、社團側欄的資訊層次；以 React 狀態取代 jQuery DOM 操作，避免舊版 name/eventName 篩選欄位不一致及社團選取樣式 selector 不一致問題。

手機將側欄改為可操作的緊湊控制，保留日期與列表切換。狀態用文字與 aria 狀態表達，不能只靠色彩。

## 限制

這是前端雛形，沒有新增活動後端、正式登入授權、資料持久化或搜尋引擎索引。載入及失敗示範僅供 UI 驗收，不能視為 API 網路錯誤處理已通過正式串接。
