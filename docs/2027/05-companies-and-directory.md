## 使用者與流程

會員提出或維護關聯公司（候選）；管理者審核與維護；訪客閱讀公開項目。

建立公司 → 選擇產業 → 關聯會員 → 設定公開資料 → 審核／發布 → 列表與詳情查詢。

## 資料草案

Company：ID、名稱、電話、地址、網址、狀態、公開設定、latitude／longitude；Industry 與 CompanyIndustry；MemberCompany。審核狀態為建議新增。

共同 ID、版本、分頁、錯誤與公開欄位規則見 [資料與介面](09-data-and-api.md)。所有範例只用合成資料。

## 功能要求

- **BIZ-01**：產業改用受控分類與多對多關聯，不以逗號字串作唯一資料來源。
- **BIZ-02**：經緯度為數值且驗證範圍；公司資料可在沒有座標時建立。網址只允許 http／https。
- **BIZ-03**：公司公開電話／地址須確認代表公司營業聯絡資訊，不將會員私人電話帶入公開回應。
- **BIZ-04**：公司與會員關聯需有授權驗證；同名公司提供重複提示但不自動合併。
- **BIZ-05**：繳費是否影響公開展示由業務決策決定，不預設付費才可上架。

## 介面候選

GET /companies?industryId=…&keyword=…；GET /companies/{id}；POST /companies；PATCH /companies/{id}；POST /companies/{id}/member-links；發布動作待審核規則確定。

以上為契約討論清單，不是已實作端點；正式 schema、欄位長度、必填與空值處理於規格定稿時補齐。畫面至少具備載入、空資料、欄位錯誤、無權限、服務失敗與衝突處理，錯誤不清除使用者未儲存內容。

## 驗收情境

- **BIZ-AC-01**：兩個產業分類的公司可各自被搜尋，結果不重複。
- **BIZ-AC-02**：沒有座標的公司仍可在名錄看到，但不產生無效地圖標記。
- **BIZ-AC-03**：未公開地址與會員私人聯絡資訊不出现在公開詳情及地图 API。

以上尚未執行；實作後由獨立驗證者依情境驗收。

## 地圖展示補充（2026-10-15）

商家地圖呈現扶輪 call name、公司名稱、所屬社團名稱與公司聯絡方式；本階段暫不顯示本人姓名，後續可依需求調整；未填 call name 時提示本人補填，不自動以姓名替代。公司聯絡方式包含公司電話、公司 Email、網站與營業地址，獨立填寫，不自動帶入會員私人聯絡資料；必填及個別欄位顯示規則另定。

沒有任何有效社籍時，預設會員查詢排除該會員，但登入使用者可勾選特殊選項查詢已退出、OB 等非正常社籍會員，仍套用欄位隱私；商家地圖以當年度社籍為免費資格，非當年度社友可付費以廣告形式曝光，不設年資門檻；付費曝光自平台管理者設定起始日起一年，到期未續費則下架地圖並保留資料；保留本人資料與歷史，多會員共用公司規則另議。商家優惠兌換須登入；優惠資料、資格、兌換流程及開發階段仍待規劃。

## 非正常社籍查詢與加購曝光（2026-10-15 最新確認）

- 會員查詢須登入；預設正常社籍，勾選特殊選項後可查已退出、OB 等非正常社籍會員，隱私及歷史公開規則仍適用。
- 當年度正常會員有社籍，商家地圖曝光免費；非當年度社友欲曝光商家，採付費會員／廣告形式，不再設定同社團年資門檻。付費曝光起始日由平台管理者設定，期限為起始日加一年，到期續費並確認商家資料，未續費則下架地圖、保留資料。付費資格不授予有效社籍或社團管理權。
- 此為地圖後續商業需求，不代表第一階段加入金流；驗證服務、收款、退款、到期下架及資料更新確認另行規劃。
