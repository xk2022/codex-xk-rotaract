## 驗證證據

- `npm run build`：TypeScript 與 Vite 正式建置通過。
- `npm test`：38 項測試通過，涵蓋社籍、年度、動態社團範圍、帳號、角色、歷史同意與支援案件。
- `npm run test:browser`：既有註冊→入社→審核、隱私、三段轉社、年度與手機流程通過，無瀏覽器錯誤。
- `npm run test:browser:v2`：新帳號操作、角色、年度、退社／OB、本人同意、支援補件／核准、新增社團入社、分頁、錯誤情境與360px版面通過。
- `python3 docs/api/validate_contract.py`：59 操作／84 DTO／626 JSON 範例靜態檢查通過，非伺服器執行驗收。
- 獨立審查已確認動態社團、跨區範圍、年度狀態、管理者退社及稽核歸屬修正，無阻擋本次初版交付問題。
