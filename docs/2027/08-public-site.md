## 使用者與流程

訪客浏览；組織管理者提供內容；平台管理者設定公開展示規則。

首頁查看社團 → 搜尋／篩選 → 社團公開详情 → 導向社團活動；從導覽前往活動或公司名錄。

## 資料草案

首頁投影：公開社團 ID、名稱、Logo、摘要、公開详情路徑；活動與公司摘要共用各模組公開規則。泡泡視覺為舊版表现方式，不是已確認新版必要形式。

共同 ID、版本、分頁、錯誤與公開欄位規則見 [資料與介面](09-data-and-api.md)。所有範例只用合成資料。

## 功能要求

- **WEB-01**：Logo 必須有文字替代；無圖片時仍顯示社團。泡泡動畫若保留，提供減少動畫選項與可鍵盤操作的列表。
- **WEB-02**：不把 ID 字串當成可直接使用的 URL；導向可識別且存在的社團詳情。
- **WEB-03**：停用、未核準公開的社團不出現在首頁、搜尋、详情與公開 API。
- **WEB-04**：公開首頁不需登入；私有內容不可透過 HTML、缓存或 API 隱藏欄位外洩。
- **WEB-05**：新版公開欄位、搜尋與 SEO 範圍待確認；不把舊模板示例導覽視為真實產品功能。

## 介面候選

GET /public/clubs；GET /public/clubs/{id}；公開活動與公司使用白名單投影。公開路徑與管理路徑分離。

以上為契約討論清單，不是已實作端點；正式 schema、欄位長度、必填與空值處理於規格定稿時補齐。畫面至少具備載入、空資料、欄位錯誤、無權限、服務失敗與衝突處理，錯誤不清除使用者未儲存內容。

## 驗收情境

- **WEB-AC-01**：手機、鍵盤操作與減少動畫模式都能找到同一社團详情。
- **WEB-AC-02**：無 Logo 的啟用社團可顯示替代圖與名稱；无效 ID 有明確不存在頁面。
- **WEB-AC-03**：停用／私有社團在直接網址與列表均不公開；公開快取在取消公開後依约定失效。

以上尚未執行；實作後由獨立驗證者依情境驗收。

## 通用會員頁面補充（2026-10-15 已確認）

未登入訪客可瀏覽商家地圖、社團行事曆；會員資料查詢與商家優惠兌換須登入後才可使用。優惠兌換的功能範圍、階段及流程另議，不因入口規則而列為第一階段交付。

會員電話預設隱藏、會員 Email 預設開啟，兩者皆可由本人以 checkbox 調整。會員資料查詢仍須登入，預設開啟不代表匿名 API 可取得會員私人欄位；授權管理者備查範圍另定。

商家地圖呈現扶輪 call name、公司名稱、所屬社團名稱與公司聯絡方式；本階段暫不顯示本人姓名，後續可依需求調整；未填 call name 時提示本人補填，不自動以姓名替代。公司聯絡方式包含公司電話、公司 Email、網站與營業地址，獨立填寫，不自動帶入會員私人聯絡資料；必填及個別欄位顯示規則另定。

沒有任何有效社籍時，預設會員查詢排除該會員，但登入使用者可勾選特殊選項查詢已退出、OB 等非正常社籍會員，仍套用欄位隱私；商家地圖以當年度社籍為免費資格，非當年度社友可付費以廣告形式曝光，不設年資門檻；付費曝光自平台管理者設定起始日起一年，到期未續費則下架地圖並保留資料；保留本人資料與歷史，多會員共用公司規則另議。

## 社團名稱、公開設定與停用（2026-10-15 已確認）

- 社長、秘書及社團管理帳號可修改自己社團名稱與社徽；一般社團管理者不可修改名稱與社徽，原有介紹／聯絡資料維護權不受影響。
- 社團名稱、類型、地區、社徽與簡介預設公開；聯絡 Email、網站／社群連結可逐項勾選是否顯示。聯絡欄位預設勾選狀態另定，不將社團 Email 與會員 Email 的隱私設定混用。
- 停用社團保留社員、社籍及歷史資料，停止新入社申請及新增活動；不因停用刪除會員帳號或覆寫社籍歷史。
- 停用社團不再提供免費地圖曝光資格；會員若另有符合條件的有效社籍，或其商家具有有效付費廣告，則依該資格顯示。停用不能撤銷獨立有效的付費曝光期間。
- 社團停用／恢復的授權者、既有待審申請與已發布活動的處理仍待確認。
